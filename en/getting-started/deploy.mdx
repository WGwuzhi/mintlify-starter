autClaw has two deployment paths: the **one-click script** (recommended) and **manual Docker**. Both use port `8200` and store data in `/opt/autclaw` by default.

| Path | Best for | What you get |
|---|---|---|
| One-click script | First-time install, minimal manual work | Downloads, verifies, installs, and starts for you |
| Manual Docker | Existing Docker or NAS setup | One `docker run` command |

## One-click install (recommended)

Run this on a Linux server:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/WGwuzhi/autClaw/main/install.sh)
```

The script re-runs itself with `sudo` when needed, then asks you to pick 4 options:

1. **Install mode**: direct / Docker
2. **Install directory**: defaults to `/opt/autclaw` (the host data directory in Docker mode)
3. **Install ffmpeg**: choose yes if you need audio or video transcoding
4. **Access port**: defaults to `8200`

If the script detects Synology DSM or Feiniu fnOS, it puts Docker first and recommends the NAS data directory.

The script then handles the rest:

- Detects `amd64` / `arm64`;
- Picks the fastest download source, then downloads and verifies the latest version;
- Direct mode installs `mise`, the runtime artifacts, and optional ffmpeg, then registers the `autclaw` service;
- Docker mode pulls the image and starts the container;
- Prints the URL, log command, and stop command once the service is ready.

When it finishes, open `http://SERVER_IP:8200`.

## Manual Docker deployment

### 1. Pick an image

| Image | Description |
|---|---|
| `nolan1121953/autclaw:latest` | Slim image (default), no ffmpeg |
| `nolan1121953/autclaw:full` | Full image = slim + ffmpeg / libavcodec-extra |

Use `:full` when you need audio or video transcoding (Feishu, WeChat Official Account, Qianxun). Neither image includes Chromium; for screenshots, see [Docker operations](/en/operations/docker).

### 2. Start the container

```bash
docker run -d \
  --name autclaw \
  --restart unless-stopped \
  --network bridge \
  -p 8200:8200 \
  -v /opt/autclaw:/opt/autclaw \
  nolan1121953/autclaw:latest
```

For transcoding, change the last line to `nolan1121953/autclaw:full`.

Then open `http://SERVER_IP:8200`. The first start takes a few minutes; follow progress with `docker logs -f autclaw`.

### 3. Feiniu OS / Synology

Only the host directory differs. The one-click script detects it and uses the directory below by default; for manual Docker, replace the left side of `-v` with the matching path:

| System | Common host directory |
|---|---|
| Feiniu OS (FNOS) | `/vol1/1000/docker/autclaw` |
| Synology DSM | `/volume1/docker/autclaw` |

For example, on Feiniu:

```bash
sudo mkdir -p /vol1/1000/docker/autclaw

sudo docker run -d \
  --name autclaw \
  --restart unless-stopped \
  --network bridge \
  -p 8200:8200 \
  -v /vol1/1000/docker/autclaw:/opt/autclaw \
  nolan1121953/autclaw:latest
```

## Change the port

Change `-p 8200:8200` to the host port you want, for example `-p 18200:8200`. Keep the container port on the right side at `8200`.
