部署完成后，日常维护主要是看日志、更新镜像和切换镜像版本。数据都在 `/opt/autclaw`，换镜像重建容器不会丢数据。

## 两个镜像版本

| 镜像 | 说明 |
|---|---|
| `nolan1121953/autclaw:latest` | 精简版（默认），不含 ffmpeg |
| `nolan1121953/autclaw:full` | 完整版 = 精简版 + ffmpeg / libavcodec-extra |

完整版多出的 ffmpeg 用于音视频转码：

- 飞书：语音转 Opus、视频转 MP4
- 微信公众号：语音转 AMR、AMR 转 WAV
- 千寻：语音转 AMR、视频转 MP4

QQ、Telegram、微信官方 Bot 发送原格式媒体，不依赖 ffmpeg，精简版就能用。

两个镜像都不含 Chromium；需要网页截图时按下方步骤临时安装。

## 查看日志

```bash
docker logs -f autclaw
```

## 停止或删除容器

```bash
docker stop autclaw    # 停止
docker rm -f autclaw   # 停止并删除
```

删除容器不会删除 `/opt/autclaw` 里的数据。

## 更新镜像

```bash
docker pull nolan1121953/autclaw:latest
docker rm -f autclaw
docker run -d \
  --name autclaw \
  --restart unless-stopped \
  --network bridge \
  -p 8200:8200 \
  -v /opt/autclaw:/opt/autclaw \
  nolan1121953/autclaw:latest
```

日常升级 autClaw 应用版本不需要重建容器，直接用网页右上角的“系统升级”即可，见 [如何升级 autClaw](/cn/getting-started/upgrade)。

## 切换精简版 / 完整版

只换镜像名，挂载目录保持不变：

```bash
docker rm -f autclaw
docker run -d \
  --name autclaw \
  --restart unless-stopped \
  --network bridge \
  -p 8200:8200 \
  -v /opt/autclaw:/opt/autclaw \
  nolan1121953/autclaw:full
```

把最后的镜像名换回 `:latest` 就是切回精简版。

## 临时补装 ffmpeg

精简版想先试试转码，可以直接在容器里安装，装完立即生效：

```bash
docker exec -it autclaw bash -lc \
  'apt-get update && apt-get install -y --no-install-recommends ffmpeg libavcodec-extra && rm -rf /var/lib/apt/lists/*'
```

<Warning>
  这样安装的软件在重建容器或升级镜像后会丢失。长期使用请直接用 `:full`，或自建镜像。
</Warning>

## 网页截图（Chromium）

Chromium 本体约 300MB，加上依赖通常超过 400MB，所以两个镜像都没有内置。需要时临时安装：

```bash
docker exec -it autclaw bash -lc \
  'apt-get update && apt-get install -y --no-install-recommends chromium fonts-wqy-zenhei && rm -rf /var/lib/apt/lists/*'
```

中文要正常显示必须装字体：`fonts-wqy-zenhei` 约 16MB，常用中文够用；`fonts-noto-cjk` 约 91MB，字形更全。

容器默认以 root 运行，Chromium 必须带 `--no-sandbox` 才能启动。插件没传这个参数时会报 `Running as root without --no-sandbox is not supported`，在插件里补上即可（chromedp：`chromedp.Flag("no-sandbox", true)`）。

## 长期使用：自建镜像

把需要的依赖直接写进镜像，重建容器也不会丢。只需要转码时直接用 `:full` 即可，不用自建；需要转码 + 截图时，可以这样自建：

```dockerfile
FROM nolan1121953/autclaw:latest
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
      ffmpeg libavcodec-extra \
      chromium fonts-wqy-zenhei && \
    rm -rf /var/lib/apt/lists/*
```

```bash
docker build -t autclaw:media .
docker rm -f autclaw
docker run -d \
  --name autclaw \
  --restart unless-stopped \
  --network bridge \
  -p 8200:8200 \
  -v /opt/autclaw:/opt/autclaw \
  autclaw:media
```

## 使用 Docker Compose

把下面的内容保存为 `compose.yaml`，然后执行 `docker compose up -d`：

```yaml
services:
  autclaw:
    image: nolan1121953/autclaw:latest
    container_name: autclaw
    restart: unless-stopped
    ports:
      - "8200:8200"
    volumes:
      - /opt/autclaw:/opt/autclaw
```

- 换版本：把 `image` 改成 `nolan1121953/autclaw:full`。
- 换目录：把 `volumes` 左边的 `/opt/autclaw` 改成 NAS 上的实际路径。
- 换端口：把 `"8200:8200"` 左边改成宿主机端口。
