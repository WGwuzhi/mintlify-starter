autClaw 是一个自托管的机器人与插件运行平台。你把服务部署到 Linux 或 Docker 后，就可以在 Web 控制台接入 IM 账号、安装插件、处理消息、支付事件、HTTP 路由和定时任务。

## autClaw 是什么

autClaw 面向需要本地部署、数据持久化和可编写插件的场景。Docker 镜像提供稳定运行基座，应用本体、前端资源、插件目录和运行时依赖默认持久化到 `/opt/autclaw`。

想先了解能力范围，查看 [autClaw 功能概览](/cn/features)。已经准备好 Docker 时，直接按 [如何用 Docker 部署 autClaw](/cn/getting-started/deploy) 启动服务。

## 常用命令

```bash
# 启动
docker run -d --name autclaw --restart unless-stopped --network bridge \
  -p 8200:8200 \
  -v /opt/autclaw:/opt/autclaw \
  nolan1121953/autclaw:latest

# 查看日志
docker logs -f autclaw

# 升级 autClaw
# 网页右上角打开“系统升级”，或在 IM 渠道发送：更新
```

<Note>
  autClaw 当前以 Linux 包单独启动和 Docker 外壳 + Linux 包启动为主，不兼容 Windows。
</Note>

## 常见问题

### autClaw 支持 Windows 吗？
不支持。当前文档以 Linux 和 Docker 部署为主。

### 插件和数据库默认存在哪里？
默认都在 `/opt/autclaw`，包括数据库、`plugin/`、`dist/`、`envs/mise` 和 `envs/packages`。
