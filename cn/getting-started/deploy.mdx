autClaw 有两种部署方式：**一键脚本**（推荐）和**手动 Docker**。两种方式都使用 `8200` 端口，数据默认放在 `/opt/autclaw`。

| 方式 | 适合谁 | 特点 |
|---|---|---|
| 一键脚本 | 第一次部署、想少手动操作 | 自动下载、校验、安装并启动 |
| 手动 Docker | 已有 Docker 或 NAS 环境 | 一条 `docker run` 命令 |

## 一键安装（推荐）

在 Linux 服务器上执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/WGwuzhi/autClaw/main/install.sh)
```

脚本会自动通过 `sudo` 提权，然后按序号选择 4 项：

1. **安装方式**：直装版 / Docker
2. **安装目录**：默认 `/opt/autclaw`（Docker 模式下是宿主机数据目录）
3. **是否安装 ffmpeg**：需要语音、视频转码时选“是”
4. **访问端口**：默认 `8200`

如果检测到群晖 DSM 或飞牛 fnOS，脚本会把 Docker 放在第一项，并自动推荐 NAS 数据目录。

之后脚本会自动完成：

- 检测 `amd64` / `arm64` 架构；
- 自动选择最快的下载源，下载并校验最新版本；
- 直装版安装 `mise`、运行产物和可选 ffmpeg，并注册 `autclaw` 服务；
- Docker 模式拉取镜像，创建并启动容器；
- 服务就绪后输出访问地址、日志和停止命令。

安装完成后访问 `http://服务器IP:8200`。

## 手动 Docker 部署

### 1. 选镜像

| 镜像 | 说明 |
|---|---|
| `nolan1121953/autclaw:latest` | 精简版（默认），不含 ffmpeg |
| `nolan1121953/autclaw:full` | 完整版 = 精简版 + ffmpeg / libavcodec-extra |

需要语音、视频转码（飞书、微信公众号、千寻）时用 `:full`。两个镜像都不含 Chromium，需要网页截图时见 [Docker 运维](/cn/operations/docker)。

### 2. 启动

```bash
docker run -d \
  --name autclaw \
  --restart unless-stopped \
  --network bridge \
  -p 8200:8200 \
  -v /opt/autclaw:/opt/autclaw \
  nolan1121953/autclaw:latest
```

需要转码时，把最后的镜像名换成 `nolan1121953/autclaw:full`。

启动后访问 `http://服务器IP:8200`。首次启动需要几分钟，可以用 `docker logs -f autclaw` 查看进度。

### 3. 飞牛 OS / 群晖

和普通 Linux 的区别只是宿主机目录。一键脚本会自动识别并把它作为默认项；手动 Docker 时，把 `-v` 左边的路径换成下表对应目录：

| 系统 | 常见宿主机目录 |
|---|---|
| 飞牛 OS | `/vol1/1000/docker/autclaw` |
| 群晖 DSM | `/volume1/docker/autclaw` |

以飞牛为例：

```bash
sudo mkdir -p /vol1/1000/docker/autclaw

sudo docker run -d \
  --name autclaw \
  --restart unless-stopped \
  --network bridge \
  -p 8200:8200 \
  -v /vol1/1000/docker/autclaw:/opt/autclaw \
  nolan1121953/autclaw:latest
```

## 修改端口

把 `-p 8200:8200` 改成你要的宿主机端口即可，例如 `-p 18200:8200`。冒号右边的容器端口 `8200` 不要改。
